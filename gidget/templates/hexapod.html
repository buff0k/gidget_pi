Control

Drag the pad to walk. Releasing it snaps back to neutral immediately - the server also forces a stop if no command arrives for half a second, so a dropped connection can't leave it walking.

Manual / Diagnostics

Drives individual Servo 2040 channels directly, bypassing gait/IK entirely - useful for bring-up with only a few servos wired, or for checking one channel's range before it's assigned in the Channel Mapping panel below. Only takes effect while Mode above is set to "Manual" - sliders are otherwise inert.

Calibration

Fine-tunes one channel's true center. Two-step process: first use "Calibrate (all servos to 90°)" above to mechanically re-seat horns against a shared, literal-90° reference; then, per channel here, nudge until it looks physically centered and save. Trim applies automatically in Idle and Walk - Manual and Calibrate-90 stay raw (untrimmed) on purpose, so they're always a trustworthy reference while calibrating.

Channel Mapping

Confirms which physical leg/joint each of the 18 channels drives. Press and hold "Test" to jog the selected channel away from neutral and back - watch which servo twitches - then assign it below. Only meaningful in Idle mode, so every other channel is sitting still at calibrated neutral while you watch.
